СТРАНИЦА DMCC — КАК ВСТАВИТЬ В TILDA

Файлы:
  dmcc-tilda-block.html — код для сайта (вставляется целиком)
  preview.html          — превью всей страницы с формой (открыть в браузере / выложить на Vercel для показа)

1. В проекте Tilda создать новую страницу (адрес: /ru/dmcc-company-setup).
2. Добавить шапку сайта (как на других страницах).
3. Добавить блок «Другое → T123 HTML-код», вставить ВЕСЬ текст из dmcc-tilda-block.html.
4. Ниже добавить форму заявки — нативный блок Tilda (как на других страницах).
   В настройках блока формы указать якорь (ссылку для якоря): quote
   Все кнопки «Получить расчёт», «Рассчитать этот вариант» и т.д. ведут на #quote.
   Поля формы по ТЗ:
     Имя (подсказка «Как к вам обращаться»)
     Телефон / WhatsApp (обязательное)
     Деятельность («Что именно будет делать компания»)
     Владельцы («Физические лица или компания; сколько владельцев»)
     Визы — выпадающий список: 0 / 1 / 2+ / Пока не знаю
     Офис — выпадающий список: Flexi desk / Co-working / Отдельный офис / Пока не знаю
     Комментарий («Страны клиентов, товары/услуги, дополнительные требования»)
   Кнопка: «Рассчитать стоимость»
   Сообщение после отправки: «Получили заявку. Подготовим расчёт с отдельными строками по DMCC, офису, визам, EFIX и ежегодным расходам.»
5. Добавить подвал сайта.
6. Настройки страницы → SEO:
   Title: Регистрация компании в DMCC в Дубае | Стоимость и сопровождение EFIX
   Description: Открытие компании в DMCC от 35 484 AED. Подбор лицензии и офиса, регистрация, визы, банк, бухгалтерия и налоги. Получите расчёт под ваш бизнес.
   Canonical: https://efix-grp.ae/ru/dmcc-company-setup
   Разметка Service + BreadcrumbList + FAQPage уже встроена в код (FAQ совпадает с видимым на странице).

ПРАВКИ ТЕКСТА
Открыть HTML-блок, Ctrl+F — найти фразу, заменить. Секции подписаны комментариями «СЕКЦИЯ 01…16».
Цены стоят как «35&nbsp;484» — &nbsp; это неразрывный пробел, чтобы число не переносилось. При замене цены сохраняйте его.

Стили изолированы классом .efx — остальной сайт не затрагивается.
Перед публикацией сверить цены DMCC (по ТЗ: package pages и Schedule of Charges).
